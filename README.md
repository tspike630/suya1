# 黍琊：醒梦之间

浏览器里的视觉小说，用 [OnscripterYuri](https://github.com/YuriSizuku/OnscripterYuri) v0.7.7beta 播放。情节仍是原来的六章。

线上地址：https://tspike630.github.io/suya1/

点击推进。右键、F9 或长按打开网页菜单，Esc 打开存档、读取、跳过、自动和回顾。F10 拉伸，F11 全屏，Ctrl 跳过。标题里可以进入回想、音乐、用语、流程和文字速度。通关后出现二周目。

引擎是 GPL-2.0，协议在 `ONSYURI-GPL-2.0.txt`，源码在上面的仓库。

```bash
npm install
npm run verify
npm run ons
npm run build
```
